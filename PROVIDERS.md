# Fornitori

Kreluna è il Perimetro. Alcuni servizi, se attivi, arrivano da fuori.

## Core (opzionale)

Se imposti `XAI_API_KEY`, Core parla in rete. Il modello si sceglie con `CORE_MODEL`.
Senza chiave, Core resta sul disco, offline.

Usare un’API non significa che il prodotto si chiami come il fornitore.

## Accesso (opzionale)

Login solo se imposti le variabili `KRELUNA_AUTH_*`.
Niente segreti nel codice.
